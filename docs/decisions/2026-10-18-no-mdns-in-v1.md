# No mDNS name in v1

Date: 2026-10-18

## Context

The user wants a name instead of an IP. The Tesla browser clipboard is
unreachable, so the URL must be typed or bookmarked. Android 11 `NsdManager`
cannot set the mDNS hostname, so `tesla-mirror.local` would need an own
responder such as JmDNS, and whether the Tesla browser resolves `.local` is
unknown.

## Decision

v1 shows the URL large in the app. Re-check it after a reboot
([hotspot-subnet](2026-10-18-hotspot-subnet.md)).

## Consequences

Candidates for v1.1:

- JmDNS responder, tried in the car.
- A car Wi-Fi router with a DHCP reservation for the phone.
